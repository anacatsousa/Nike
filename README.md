## Getting Started

**Prerequisites**
- **Node.js** (v18 or higher recommended)
- npm


**Running locally**

1. Clone the repository:
```bash
git clone https://github.com/anacatsousa/Nike.git
cd Nike/nike
```

2. Install dependencies:
```bash
npm install
```

3. Start the development server:
```bash
npm run dev
```

4. Open **http://localhost:5173** in your browser.
